# Little Lemon Client

The frontend for the Little Lemon restaurant project.

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
npm run preview
```

Configure the API URL in `.env`:

```env
VITE_API_BASE_URL=http://localhost:5000
```

The interface uses React, Vite, Material UI, React Router, React Hook Form, and Zod.
